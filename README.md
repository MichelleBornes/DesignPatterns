# Design Patterns em Java

Repositório dedicado aos estudos e à implementação de **Padrões de Projeto (Design Patterns)** utilizando Java, como parte das atividades acadêmicas da disciplina de Padrões de Projeto.

O objetivo é compreender os conceitos, a estrutura e a aplicação prática dos padrões, desenvolvendo soluções que favoreçam a reutilização, a organização, a flexibilidade e a manutenção do código.

## Objetivos do repositório

- Compreender os principais padrões de projeto da programação orientada a objetos.
- Desenvolver implementações práticas utilizando Java.
- Aplicar princípios de orientação a objetos e SOLID.
- Identificar problemas de desenvolvimento que podem ser resolvidos com padrões de projeto.
- Desenvolver código organizado, reutilizável e de fácil manutenção.

## Conteúdo

### Fundamentos e princípios SOLID

| Conteúdo | Descrição |
|---|---|
| Herança | Reutilização de atributos e métodos entre classes. |
| Polimorfismo | Utilização de diferentes implementações por meio de uma interface ou classe comum. |
| SRP | Single Responsibility Principle — responsabilidade única. |
| OCP | Open/Closed Principle — aberto para extensão e fechado para modificação. |
| LSP | Liskov Substitution Principle — substituição de Liskov. |
| ISP | Interface Segregation Principle — segregação de interfaces. |
| DIP | Dependency Inversion Principle — inversão de dependência. |

### Padrões de projeto

Os padrões estão organizados de acordo com suas categorias:

#### Criacionais
Padrões relacionados à criação de objetos.

- **Factory Method:** delega às subclasses a definição dos objetos que serão instanciados.
- **Abstract Factory:** fornece uma interface para criação de famílias de objetos relacionados.
- **Singleton:** garante uma única instância de uma classe.
- **Prototype:** permite criar novos objetos a partir da clonagem de objetos existentes.

#### Estruturais
Padrões relacionados à organização e composição de classes e objetos.

- **Adapter:** permite a integração entre interfaces incompatíveis.
- **Decorator:** adiciona responsabilidades a objetos dinamicamente.

#### Comportamentais
Padrões relacionados à comunicação e distribuição de responsabilidades entre objetos.

- **Observer:** estabelece uma relação de notificação entre um objeto observado e seus observadores.
- **Strategy:** permite selecionar e substituir algoritmos ou comportamentos durante a execução.

## Como executar os projetos

1. Clone o repositório:

```bash
git clone https://github.com/MichelleBornes/DesignPatterns.git
```

2. Acesse o diretório do padrão desejado:

```bash
cd DesignPatterns
```

3. Abra o projeto em uma IDE compatível com Java, como IntelliJ IDEA, Eclipse ou VS Code.

4. Execute a classe principal (`Main`) ou a classe indicada em cada exercício.
